Email Sender

A private automation tool used by one person on his own computer.

Email Sender is the Google OAuth client of a personal set of automation scripts. It lets the owner's local tools read and send his own e-mail, read his calendar and work with files in his own Google Drive - for example to file test reports or find a document.

  • It is not a public service. There is no sign-up and no other users.
  • It runs only on the owner's computer; no server stores any Google data.
  • Access can be revoked at any time at myaccount.google.com/permissions.
